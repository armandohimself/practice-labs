## How to Use

Each problem includes:

- **Implementation file**: Contains the problem description, examples, and a starter method with TODO
- **Test file**: Contains comprehensive test cases using JUnit 5

### Running Tests

```bash
# Run all LeetCode tests
./gradlew test --tests "practice.leetcode.*"

# Run specific category tests
./gradlew test --tests "practice.leetcode.arrays.*"
./gradlew test --tests "practice.leetcode.strings.*"
./gradlew test --tests "practice.leetcode.trees.*"

# Run a specific problem
./gradlew test --tests "practice.leetcode.arrays.TwoSumTest"
```

### Implementation Pattern

All problems follow this pattern:

```java
public class ProblemName {
    public ReturnType methodName(Parameters params) {
        // TODO: Implement your solution here
        return defaultValue;
    }
}
```

You implement the logic inside the method, and the tests will automatically validate your solution.

### Multiple Attempts

The test infrastructure supports multiple attempts:

- Create `ProblemName2.java`, `ProblemName3.java`, etc.
- Tests will automatically use the latest version
- Or override with environment variable: `PRACTICE_TARGET=ProblemName2 ./gradlew test`

## Study Tips

1. **Start with Easy categories**: Arrays, Strings, Linked Lists
2. **Progress to Medium**: Trees, Dynamic Programming
3. **Finish with Hard**: Graphs, Heaps, Advanced DP
4. **Focus on patterns**: Each category teaches specific problem-solving techniques
5. **Iterate**: Try multiple solutions, optimize time/space complexity

## Common Patterns

- **Sliding Window**: Longest Substring, Minimum Window
- **Two Pointers**: Container With Most Water, Valid Palindrome
- **Fast & Slow Pointers**: Linked List Cycle
- **Merge Intervals**: Insert Interval, Merge Intervals
- **Cyclic Sort**: Missing Number
- **Binary Search**: Search in Rotated Array, Find Minimum
- **Top K Elements**: Top K Frequent Elements
- **K-way Merge**: Merge K Sorted Lists
- **BFS/DFS**: Number of Islands, Clone Graph
- **Backtracking**: Combination Sum, Word Search
- **Dynamic Programming**: House Robber, Climbing Stairs
